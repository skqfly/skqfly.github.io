# Trinote 手机入口与同步日志

Trinote 不会运行 Trilium 的 render 脚本面板。手机上请直接打开“博客管理”及其中的文章、Talks、Photos、友链、项目、站点设置、图片素材文件夹；这些入口使用原生富文本、笔记链接与字段，不依赖网页脚本。

## 在 Trinote 中使用

1. **修改**：打开对应条目，使用原生编辑器修改正文；标题下方填写日期、摘要、链接等字段。
2. **新建**：在分类中使用“＋ / 新建子笔记”，通过模板选择器选择对应的文章、动态、照片、友链或项目模板。不要使用“克隆”或复制固定链接 ID。
3. **图片**：在图片素材中打开详情 → 附件 → 上传相册或文件，再长按附件 → Convert to note（转换为笔记）。在内容的“选择图片 / 选择照片”字段中选择对应图片或照片条目。
4. **提交**：保存后打开“提交发布”开关。同步成功后会自动复位，可再次提交；未提交的原生编辑不会夹带到其他发布中。
5. **立即执行**：点文件夹中的 GitHub 同步工作流链接，登录 GitHub 后点击 Run workflow。也可在手机浏览器中使用网页版管理面板点击发布。Trinote 原生开关只登记请求，不执行 JavaScript，因此不能直接调用 GitHub；定时检查仅作后备，可能延迟。
6. **下架 / 恢复**：打开或关闭“从网站下架”，再打开“提交发布”，然后执行同步。原笔记保留。
7. **排错**：每个分类都有“查看同步日志”，可看当前阶段、出错笔记/字段、文件变化、GitHub 完整日志、部署结果及历史记录。

## 日志覆盖范围

日志记录准备环境、读取与校验、构建博客、提交与推送、触发部署及最终部署结果。校验失败会给出条目标题、ID 和字段，并提供定位原笔记的链接。触发失败、权限不足、缺少令牌等情况也会写入原生日志。Trilium 连接本身不可用时无法回写，请直接打开 GitHub 工作流日志。

以下是电脑或手机浏览器的管理面板说明。

# 博客管理

打开同目录的 **博客管理面板 · 编辑与发布**，即可管理博客。不用手动修改标签，也不用开启后端脚本。即时触发会使用“高级发布设置 → 即时发布配置”中已保存的私有 GitHub 发布令牌。

## 编辑、添加和发布

1. 点击“文章 / Talks 动态 / Photos 照片 / 项目 / 友链”等分类。
2. 点击现有内容编辑，或点击“＋ 新增”。标题、日期、简介、图片等均有表单。
3. **保存草稿**：保存到 Trilium，线上继续保留上次发布的版本。
4. **保存并发布**：保存后提交发布请求。
5. **发布全部更改**：提交所有保存的内容，包括草稿和待下架内容，提交前会列出数量确认。

点击发布会先保存内容，再立即调用 GitHub 工作流，面板会显示“已触发 GitHub”及发布记录链接。随后 GitHub 校验、构建、提交并触发部署，网站更新仍需几分钟。查看面板中的“上次同步结果”及“查看发布进度”链接。同步成功表示内容推送完成；部署完成后网站才更新。

如果没有配置令牌、令牌失效或网络出错，面板会明确显示“已排队，尚未触发 GitHub”及原因。内容不会丢失，可检查配置后再次发布，或在发布进度页点击 Run workflow 手动执行。定时检查仅作为后备，GitHub 调度可能延迟，不能依赖它实现即时同步。

发布令牌只在当前已登录会话点击发布时临时读取，并仅发送给固定的 GitHub 工作流接口；不会写入管理台脚本、页面、浏览器存储或仓库。细粒度令牌需对本仓库具有 Actions 写权限。

## 图片与头像

- **头像**：直接预览、导入本地图片、从图片库选择、移除或导出原图。移除后恢复网站内置默认头像。
- **Photos**：可一次导入多张照片，自动读取宽高并创建照片草稿。填写说明后发布即可加入图库。
- **Talks**：勾选照片缩略图添加配图，取消勾选移除。
- **文章 / 项目 / 友链**：可预览封面或头像、导入图片、从图片库选择和导出；文章还可以将图片插入 Markdown 正文。
- **图片库**：集中预览、导入、导出原图和移入回收站。原文件保存在 Trilium；发布时生成 WebP 和缩略图。
- 支持 JPG、PNG、WebP、GIF、AVIF，单张不超过 15 MB，解码总像素不超过 4000 万。只有被已发布内容引用的图片会导出，草稿图片不会公开。

请通过管理面板导入并选择图片。直接粘贴 Trilium 内部附件地址不会自动转成博客地址。

## 删除和恢复

- **删除 / 下架**：内容移入管理台回收站并提交下架请求。同步部署完成后，对应页面或卡片从网站删除。
- **回收站 → 恢复**：恢复为草稿；再“保存并发布”重新上线。
- 删除 Photos 条目会同时移除 Talks 对它的引用。恢复照片后可重新勾选配图。
- 图片库中仍被已发布内容引用的图片继续保留在线上，避免其他页面破图。
- 原始笔记保留，可恢复或导出；不要直接删除原笔记来下架内容。

## 导出与高级编辑

“导出内容”下载正文和属性 JSON；图片可单独导出原始文件。文章正文用 Markdown，站点设置按段编辑 JSON。
原笔记目录也保留。日常推荐使用管理面板。不要用 Trilium 的“克隆”创建新文章，克隆共享同一份正文。
请在 Trilium 编辑已接管内容；同时手工改 GitHub 中同一内容，可能被下一次同步覆盖。
