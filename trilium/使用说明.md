# 在 Trilium 管理博客

此目录是 skqfly 博客的内容管理入口。只有这个目录中的内容参与同步。

## 编辑和发布

1. 在文章、动态、照片、友链或项目目录打开对应笔记。
2. 正文直接编辑，字段在右侧“属性”中填写。保留 `blogKind` 和 `blogId`。
3. `publish` 标签表示“允许发布这份内容”。没有此标签的草稿不会覆盖已发布版本。
4. 写完后添加 `publish` 标签；已发布的内容，请将该标签值改为当前日期时间或新的版本号。GitHub 约每 5 分钟检测这些发布信号，实际调度可能更晚。只改正文不会自动发布。
5. 如已启用 Trilium 后端脚本，可打开“发布面板”点击同步。配置专用令牌后支持即时触发，否则写入定时队列。标签检测不依赖后端脚本，始终可用。

点击同步会发布目录里所有带 `publish` 标签的内容。建议新内容写完再加标签。
发布过程包含：读取和校验 → Astro 构建 → Git 提交和推送 → 触发 GitHub Pages 部署。
“同步成功”表示内容已推送且部署已触发；网站是否上线以部署工作流结果为准。

## 各类内容

- **文章**：Markdown 正文；属性 `blogKind=post`、`blogId`（保持原文章文件名，英文数字、下划线或连字符）、`pubDate`（YYYY-MM-DD）、`description`、`author`、`category`、`image`、`imageAlt`。笔记标题就是文章标题。
- **动态**：正文为动态文字；属性 `blogKind=talk`、`blogId`、`date`；`photos` 是照片 ID，用英文逗号分隔。
- **照片**：正文为图片说明；属性 `blogKind=photo`、`blogId`、`src`、`width`、`height`、`preview`、`previewLarge`。可用图床 HTTPS 链接或站内已有 `/photos/…` 路径。请填写图片真实尺寸。暂不自动上传 Trilium 内嵌图片，也不生成外部图片缩略图。
- **友链**：正文为介绍；属性 `blogKind=friend`、`blogId`、`url`、`domain`、`image`。
- **项目**：正文为介绍；属性 `blogKind=project`、`blogId`、`url`、`image`、`categories`、`tags`；后两项用英文逗号分隔。
- **站点设置**：分段 JSON 笔记，编辑首页、导航、社交链接、SEO、关于页等。不在这里编辑 entries/friends/projects，使用独立内容笔记。

新内容请新建 Markdown 代码笔记，参照同类型笔记填写属性，写完再添加 `publish`。不要用 Trilium 的“克隆”创建新文章：克隆共享同一份正文和属性。不同内容不得使用同一类型和 ID。
文章图片可直接使用外部 HTTPS URL 或博客已有路径；Trilium 内部的笔记/附件地址不能直接给博客访客访问。

## 草稿、删除与冲突

- 移除 `publish` 只停止更新，不删除线上版本。
- 删除笔记不会删除线上内容；当前版本不支持在 Trilium 下架文章，避免误删。
- 已接管的内容请在 Trilium 编辑。在 GitHub 修改同一内容可能被下一次同步覆盖。
- 校验或构建失败不会推送；失败结果会写回 `blogSyncStatus`。
- 图片、UI 组件、样式、部署配置和任意脚本不属于内容编辑范围。
- 没有专用 GitHub 令牌时，“同步”会排队，GitHub 定时任务约每 5 分钟检查一次；GitHub 调度可能更晚。可手动运行 Trilium 工作流立即处理。

## 可选的即时发布

创建仅授权 `skqfly/skqfly.github.io` 的 GitHub fine-grained token，仓库权限只需 **Actions: Read and write**，将其填入“即时发布配置”的 JSON：`githubToken`。
该配置只保存在 Trilium 私有笔记中，不会导出到博客或 GitHub。
即时同步调用 `workflow_dispatch`；没有令牌时仍可使用定时队列，不影响内容编辑。
